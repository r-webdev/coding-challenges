# WebDev Challenges

A collection of coding and technical challenges run in the WebDev community. Each challenge is documented here as a standalone markdown file, covering the task, goals, and any resources needed to get started.

## How it works

- Each challenge lives in its own folder under `challenges/`.
- A challenge can be anything: a coding task, a deployment exercise, a debugging puzzle, or a broader project brief.
- Challenges are meant to be practical, hands on, and relevant to real world web development and dev ops skills.
- Members are encouraged to share their progress, ask questions, and compare approaches in the server.
